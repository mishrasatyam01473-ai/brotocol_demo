# XYZ Hotel - Luxury Guest Mobile Portal (Brotocol Demo)

An ultra-fast, mobile-first guest digital portal and concierge dashboard for **XYZ Hotel & Resort**.

## ✨ Features
- **Instant Dining Menu**: Direct, pre-loaded access to Koyla fine dining and cocktail menu.
- **Google Reviews Integration**: 1-tap redirect to write and view Google reviews.
- **Instagram Portal**: Instant access to official social stories, reels, and highlights (@koyla__).
- **Complimentary Wi-Fi Access**: 1-click password copy with haptic feedback.
- **Direct Concierge Assistance**: Fast-dial reception and direct WhatsApp concierge.
- **Aurora Cosmic Aesthetic Theme**: Fluid GPU-accelerated glowing cosmic atmosphere.
- **Mobile Performance Optimized**:
  - Non-blocking asynchronous font loading
  - Zero Cumulative Layout Shift (CLS = 0)
  - Preloaded critical menu assets
  - DNS prefetching for external services
  - Native browser touch handling with vibration feedback

## 🚀 Quick Start

### Installation & Development
```bash
cd frontend/brotocol
npm install
npm run dev
```

### Production Build
```bash
cd frontend/brotocol
npm run build
npm run preview
```
